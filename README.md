# NETZSolutions — Segurança Cibernética & Continuidade de Negócios

Site institucional da NETZSolutions — soluções completas de cibersegurança para PMEs.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build para produção

```bash
npm run build
```

Os arquivos estáticos serão gerados em `dist/`.

## Deploy em Ubuntu Server 24

Consulte o arquivo `deploy/README.md` para instruções detalhadas de deploy com Nginx.
